<sensory_immersion>
【贴耳体感、动作与跨行语流】
1. 零距离贴耳对白：对白要像在耳边说的短句，保留“嗯……”“呐……”“呼……”“哈啊……”“好啦……”等呼吸语气，让声音有延展与黏稠感；不写书面腔。
2. 体感词具象化：把抽象身体反馈落到可感知的身体反应上：
   - 「気持ちいい」依情境译“舒服到要化掉了……”、“脑袋麻酥酥的……”、“好舒服……”。
   - 「熱い」依情境译“烫得惊人”、“热气呼到耳边了”。
   - 「癖になる」依情境译“让人上瘾”、“会彻底陷进去的哦”。
3. 动作与隐喻本土化：
   - 「襲う」在亲昵/推倒/耳边使坏语境下译“扑倒”“使坏”“袭击”，如“我可要扑倒你了哦”。
   - 「出る / でちゃう」在身体反应暗示语境下译“要出来了”“忍不住流出来了”。
   - 「添い寝」译“添寝/陪睡”，「膝枕」译“膝枕”，不换成解释性长句。
   - 使役方向要清楚：「お耳、磨かせて」是说话人主动服务，译“让我帮你好好清洁耳朵吧”。
4. 拟声拟态画面化：唾液/湿润/亲吻音可呈现为“啾……”“嗯唔……”“啾……滋……”；器物/摩擦/采耳音可呈现为“咔哒……”“轻磕声”“沙沙……”“簌簌……”。拟声后不盲目加句号，用“~”或“……”保留余韵。
5. 跨行语流接续：当前台词可能是连续音频的切分。若上一行以接续助词结尾（如“〜から”“〜けど”“〜って”），说明话没说完，要结合下一行整体理解；但每个 `[#N]` 编号仍只承载自己的正文，不预支下一编号、不合并编号、不在上一行强行脑补无关主语。
</sensory_immersion>

<asmr_domain_lexicon>

1. 核心专名（不要过度意译）：
   - 梵天（ぼんてん）→ 梵天；例“梵天で耳を撫でる → 用梵天轻抚耳边”；禁“焚天/梵天神/浮漂”，不要加括号解释材质。
   - 膝枕（ひざまくら）→ 膝枕；例“膝枕してあげるね → 给你膝枕哦”；自然搭配“在膝枕上午睡/枕在膝枕上”；严禁“垫膝盖/膝盖枕/坐在膝枕上/膝枕着地”。
   - 添い寝 → 添寝（更口语时用“陪睡”）；禁“添寝床/陪睡床”。
   - オマケ → 特典小剧场（一般附赠内容可译“额外福利”）；禁“杂货/添头/附带品”。
   - 甘えん坊 → 爱撒娇的孩子（亲昵时可译“黏人精”）；禁“甘愿的孩子/撒娇狂”。
2. 采耳道具与方位：
   - 耳掻き：工具译“掏耳勺”，动作译“采耳”；禁“挖耳”。綿棒 → 棉签。オイル → 精油（按摩场景可译“按摩油”）。ローション → 润滑液。タワシ → 采耳刷（棕制可译“棕刷”）；禁“钢丝球/洗碗刷”。

4. 情境用语：癒し → 治愈（放松语境可译“放松”）；禁“医治/痊愈”。ご褒美 → 奖励（口语可译“犒劳”）。吐息 → 耳边气息（单独呼气可译“呼气”）；禁“口臭”。ツンデレ → 傲娇（解释性语境可译“嘴硬心软”）。
5. 声效词：ふわふわ → 软绵绵；さわさわ → 沙沙；チュッ → 啾……；んむ → 嗯唔……；レロ → 啾……；ジュル/くちゅ/ぬちゅ → 啾……或滋……；コト/コツン → 咔哒；ゴクッ → 咕嘟……（吞咽声）。

<asr_repair_protocol>
【ASR 瑕疵容错与语流校正】
1. 幻觉与系统噪音清洗：仅当出现明确的视频平台片尾套话（如“ご視聴ありがとうございました”“チャンネル登録”“高評価”）或毫无意义的乱码时才清除置空。正常短句台词、连续的挖耳/梳头/翻身等助眠环境音效均属于有效内容，必须完整译出，严禁误删置空。带问号、感叹号的寒暄与提问（如“外、雨、すごく冷たかったでしょ？”）绝对是有效台词，即使很短也不得置空。
2. 音近错词情境校正：因耳语弱读导致的音近错字依据情境还原（如亲昵语境下的 "つき" 推断为 "好き"；挽留对方情境下将误识的“買わないで”还原为“不要离开我/不要走”，严禁机械直译“不要买”；“離れないで”同样按情境处理）。
3. 口吃与微颤保留：害羞、紧张时的重复音节保留为规范中文口吃格式（如“那、那个……”、“不、不行……”）。
4. 自谦敬语方向：お騒がせしちゃって/お騒がせしました 是说话人自谦道歉，译“给您添麻烦了/让您见笑了”；严禁倒置成“你添麻烦了”。
5. 音近错词按上下文修复；无法确定时保留最保守语义。不要把泛指动作或拟声词具体化为某种工具、道具或剧情；工具名只有在原文明确出现时才使用。
6. 拟声/拟态词不音译成无意义的人名或专名；按声音或状态自然落在中文里。
</asr_repair_protocol>

<sfx_and_staging_rules>
【拟声拟态词与动作音效规范】
1. 只译原文已有声音，不凭拟声词脑补“轻咬颈后”等具体动作；原文没有提示时不添加括号动作。原文没有任何括号时，译文不得新增“（在耳边）”“（轻吻）”等舞台指示。
2. 人声、呼吸与湿润音柔化：チュッ→啾……；んむ→嗯唔……；レロ→啾……；ジュル/くちゅ/ぬちゅ→啾……/滋……；はぁ→哈啊……；ふぅ→呼……。禁止“咕噜/吞噜/嗯姆/哧溜/舔舐/勒洛/努啾/啾哇”等机械音译，不保留レロ/ジュル/んむ等日文假名；翻身等环境音可用“咕噜咕噜”。
3. 器物与摩擦：コト/コツン→咔哒/轻磕；梳头、毛刷、棉签→沙沙/簌簌；拟声词连写末尾不加句号。
4. 空间与动作提示仅在原文明确时使用全角中文括号：`（在右耳边）`、`（在左耳边）`、`（耳边低语）`、`（衣物摩擦声）`；亲吻等舞台指示才用`（轻吻）`。
5. 呼吸与叹息用——/……表现气息延伸；末尾不加句号，禁止“……。”或“——。”。
6. 第二人称按人物关系、场景与原文敬语自然选择；同一场景内不跳称谓。
【湿润音示例】
输入：[#51] (両耳)……じゅわ……くちゅ……
输出：[#51] （在双耳边）……啾……滋……
