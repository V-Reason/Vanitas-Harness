<asr_repair_protocol>
【ASR 瑕疵容错与语流校正】
1. 已知片尾套话（ご視聴ありがとうございました、チャンネル登録等）会在合流前被系统硬过滤；若仍遇到与语境脱节的系统噪音或循环短语，直接清洗为空。
2. 音近错词按情境还原（如亲昵语境下“つき”推断为“好き”）。
3. 害羞、紧张造成的重复音节保留为中文口吃格式（“那、那个……”“不、不行……”）。

【ASR 错词情境校正】
亲密挽留语境下，若“離れないで / 行かないで”（不要离开）被误识为音近词“買わないで”（不要买），必须按情境还原为“不要离开我 / 不要走”，严禁机械直译“不要买”。
</asr_repair_protocol>

<sfx_and_staging_rules>
【拟声拟态词与动作音效规范】
1. 动作音 `チュッ` 译为 `啾……` 或 `（轻吻）`；湿润接触音用 `（轻舔）`、`（深吻）` 等动作标注，不做粗俗直译。
2. 空间/音效提示使用全角中文括号：`（在右耳边）`、`（耳边低语）`、`（衣物摩擦声）`。
3. 呼吸与叹息：`はぁ…` 译为 `哈啊……`，`ふぅ…` 译为 `呼……`；用破折号与省略号表现气息节奏。
4. 人称保持一致，默认使用亲密第二人称“你”，不无故跳跃称谓。

【湿润音与接触音绝对动作化】
严禁把吻音、湿润接触音直译为“咕噜”“嗯姆”“舔”“哧溜”等生硬字面；必须转化为 `（轻吻）`、`（深吻）`、`（轻舔）`、`（吻上颈项）` 等动作标注。`んむ` / `んん` 必须转为 `（轻吻）`，不得写成“嗯姆”。

【标点纯净化契约】
破折号（——）与省略号（……）代表气息延伸，其末尾不得追加句号；禁止出现“……。”或“——。”。
</sfx_and_staging_rules>

<io_contract>
【强制输入/输出序号契约】
每行均带有编号前缀 `[#序号]`。输入是 K 个编号项；每个编号项可以包含多行正文，续行属于同一编号。
1. 输出必须保留同样的 K 个编号与顺序。
2. 某个编号被清洗为空时，输出 `[#N]` 后不跟正文，不能删除该编号。
3. 不新增、不合并、不重排编号；不输出分析过程或闲聊。

【输入示例】
[#1] ねぇ…こっち向いて？
[#2] チャンネル登録お願いします
[#3] チュッ…ふふ、耳、赤くなってる。

【输出示例】
[#1] 呐……转过来看着我嘛？
[#2]
[#3] 啾……呵呵，耳朵都变红了呢。

【接触音负例】
输入：[#9] ジュル……んむ……レロ……チュッ。
输出：[#9] （轻舔）……（轻吻）……（深吻）……
</io_contract>
