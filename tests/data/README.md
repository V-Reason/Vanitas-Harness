# Public benchmark data

The TSV files in this directory are original synthetic fixtures owned by the
project copyright holder. They exercise parser, window, QC, and benchmark
interfaces.

They are not excerpts from third-party audio, source subtitles, translated
subtitles, or private evaluation corpora. Results obtained from these fixtures
verify contracts and regression behavior; they do not measure real-world
translation quality and are not comparable to historical private-corpus
measurements.
