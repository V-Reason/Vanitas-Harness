# ASMR 字幕生成与测试

> 适用范围：`<ASMR_ROOT>` 下的日语 ASMR 音频。
> 目标：生成可翻译、可人工审阅的日语 SRT，不追求“全自动无人校对”。
> 当前状态：**参数已冻结，等待扩样本验证；尚未批量 80 个。**

## 1. 已验证环境

| 项目 | 值 |
|---|---|
| SubtitleEdit | v5.3.0 |
| ASR 引擎 | Purfview Faster-Whisper-XXL |
| 模型 | `large-v3`（3.1 GB） |
| 语言 | Japanese / `ja` |
| 计算 | `cuda` + `float16` |
| VAD | Silero v4 |
| 输出 | SRT，UTF-8，不加语言后缀 |

## 2. 冻结参数

在 SubtitleEdit 的“高级设置”里只填下面这一行。  
**必须是单行，不能有真实回车/换行**；界面自动折行没关系。

```text
--device cuda --compute_type float16 --temperature 0 --best_of 5 --beam_size 5 --repetition_penalty 1.1 --initial_prompt None --condition_on_previous_text False --temperature_increment_on_fallback 0.2 --compression_ratio_threshold 2.4 --logprob_threshold -1.0 --no_speech_threshold 0.6 --hallucination_silence_threshold 2.0 --word_timestamps True --vad_filter True --vad_threshold 0.4 --vad_min_speech_duration_ms 300 --vad_max_speech_duration_s 25 --vad_min_silence_duration_ms 600 --vad_speech_pad_ms 450 --vad_method silero_v4 --max_line_width 20 --max_line_count 2 --beep_off
```

SubtitleEdit 会自动追加：

```text
--language ja --model "large-v3" --output_dir <临时目录> "<音频路径>"
```

### 2.1 关键取舍

| 参数 | 作用 |
|---|---|
| `--vad_threshold 0.4` | 比 0.5 更敏感，补回轻语；比 0.35 少收噪声 |
| `--vad_speech_pad_ms 450` | 300 会切尾，900 会带气声 |
| `--vad_min_speech_duration_ms 300` | 保留短促耳语 |
| `--vad_min_silence_duration_ms 600` | 默认 3000 会把多句合并 |
| `--vad_max_speech_duration_s 25` | 防止长块漂移/循环 |
| `--vad_method silero_v4` | 较新的 Silero VAD |
| `--hallucination_silence_threshold 2.0` | 跳过静音段幻觉 |
| `--initial_prompt None` | 禁止旧 prompt 的 `はぁ、ふぅ、チュッ` 污染 |
| `--condition_on_previous_text False` | 避免错误上下文滚雪球 |
| `--beam_size 5` + `--temperature 0` | 确定性 beam search |
| `--repetition_penalty 1.1` | 轻度压重复，不压掉拟声词 |
| `--max_line_width 20 --max_line_count 2` | 20 字 × 2 行，替代 `--standard_asia` |
| 不加 `--sentence` | 避免把 `気持ちいい`、`綿棒` 切成跨 cue 碎片 |

### 2.2 不要使用

```text
--standard_asia
--sentence
--no_speech_strict_lvl   # 当前构建不支持
--reprompt 0             # 当前构建按 bool 解析，0 会报错
--v3_offsets_off         # 会关闭 large-v3 的反幻觉偏移
--initial_prompt "..."   # 旧风格污染
--ff_mdx_kim2 / --ff_speechnorm / --ff_fftdn / --ff_gate
```

`--standard_asia` 会启用 16 字 × 2 行、`--sentence` 和 `max_comma_cent=80`，在 2026-10-28 的实测中导致：

- 日文之间插入空格：`ね えねえ`、`それ じゃ`；
- 关键短语跨 cue 断裂：`気` / `持 ちいい?`、`綿` / `棒`、`ホテル` / `じゃない`；
- 翻译层出现重复或误译：`可以握住吗？`、`用棉签。棒子可能不行`。

删掉 `--standard_asia`，改用 `--max_line_width 20 --max_line_count 2` 后，`②用棉棒轻轻清洁耳朵_3.srt` 恢复正常。

## 6. 测试流程

### 6.1 备份

批量前先复制旧 SRT，不要覆盖：

```powershell
$root = '<ASMR_ROOT>'
$backup = Join-Path $root ('_srt_backup_' + (Get-Date -Format 'yyyyMMdd_HHmmss'))
New-Item -ItemType Directory -Path $backup -Force | Out-Null
Get-ChildItem -LiteralPath $root -Recurse -File -Filter *.srt | ForEach-Object {
    $rel = $_.FullName.Substring($root.Length).TrimStart('\')
    $dst = Join-Path $backup $rel
    New-Item -ItemType Directory -Path (Split-Path $dst) -Force | Out-Null
    Copy-Item -LiteralPath $_.FullName -Destination $dst
}
```

### 6.2 单文件

1. 清空队列，只添加一个音频；
2. 确认高级参数是单行；
3. 后处理设置不变；
4. 生成后先看前 5 分钟，异常立即停；
5. 保留旧文件，新文件用独立后缀或输出目录。

### 6.5 自动 QC

批量前后统一跑只读检查：

```powershell
python scripts\qc_srt.py --source-dir "<ASMR_ROOT>\SRT" `
  --zh-dir "<ASMR_ROOT>\SRT"
```

- error（阻断）：cue 数/序号/时间轴不一致、`[#N]` 泄漏、不同原文同长/覆盖译文；
- actionable（默认不阻断）：ASR 疑词、亲昵语境“您”、未授权动作括号、译文长度异常、非幻觉空译、假名残留；
- silent（静默计数）：繁体、行首标点，由翻译后处理覆盖，不再逐条刷 warning；
- `--json` 输出 `summary` 与 `flagged_cues`，`files`/`errors`/`warnings` 保留兼容；`--strict` 让 actionable 也返回 `1`。
- 终端只打印紧凑 `- 原文/+ 译文/? 建议` Diff，不再输出 Markdown 表格。

## 7. ASMR 提示词优化 backlog

当前 `task_translate_asmr.md` 的领域词典对采耳/道具覆盖较好，但对“日常口语”和“反过度套用”还不够。

### 7.1 已观察到的翻译问题

| 日文 | 当前中文 | 期望方向 |
|---|---|---|
| `ニヤニヤしてる` | 撒着笑 | 坏笑/偷笑 |
| `ネットの方がいい?` | 用网 | 上网/网上 |
| `ゾリってした時` | 采耳刷 | 轻轻刮/蹭 |
| `塗ってあげよう` | 犒劳一下 | 给你涂 |
| `その反応` / `好きなんだ` | 那样的反应 / 我喜欢你 | 我喜欢你这种反应 |
| `されるの` | 被你这样对待 | 被这样对待/被弄 |

### 7.2 本轮已实施（2026-10-29）

提示词只加通用规则，不写死单部音频的角色名/作品名，也不使用“禁止您”这类一刀切禁令：

1. 新增 `<language_and_voice>`：默认简体中文；第二人称按人物关系、场景与原文敬语自然选择；专名首次确定后全篇复用；不添加原文没有的动作/工具/剧情。
2. `<counting_and_io_guardrails>` 增加：每个编号只译当前原文；正文任意位置不得出现 `[#N]`；无法确认时保守直译，不借用相邻行。
3. `<asr_repair_protocol>` 增加：音近错词按上下文修复，无法确定时保留最保守语义；不把泛指动作/拟声词具体化为工具；拟声词不音译成无意义人名。
4. `<sfx_and_staging_rules>` 的第二人称规则改为“按关系与场景选择”，不再写死“默认你”。

同时新增翻译窗口结构守卫：窗口译文正文出现 `[#N]`、非空原文对应空译文，或不同原文得到相同长译文时，整窗回退逐句；逐句结果在 cue 边界清理 `[#N]`（不是全局删除批次编号）。

- **P0 修复**：旧 `sanitize_translation_output()` 全局删除 `[#N]`，导致 `TranslationEngine` 的批次响应在 `parse_window_response` 前就丢掉编号；实测 2-cue 窗口会发 3 次请求（1 批次 + 2 逐句），两条 cue 都被写成 `译一译二`。已删除全局清洗，编号只在 cue 边界由 `strip_window_id_prefix()`/`postprocess_cue_text()` 清理；新增批次编号保留与单句多编号拒绝回归测试。

- **实体引擎**：`DynamicEntityEngine` 从全篇片假名、敬称名、3–4 字汉字块共同前缀提种子，停用表过滤普通词/拟声词；变体按包含/首字近似/编辑距离聚类。`capture_translations()` 仅在源行以实体开头且后接标点、译文前 2–4 字后接标点时高置信锁定，其余存前文示例；`get_query_context()` 注入变体/锁定名/示例；`enforce_locks()` 只清未翻译日文专名。仅 `window_size>1`（ASMR W=6）启用，且叠加滑动前文而不是替换。
