### 2.1 7B 分片规则（必须遵守）

- `llama.dll` 内含 `%s-%05d-of-%05d.gguf` 与 `split.count`，`llama-server` 只需传**第 1 片**，会按文件名自动续载第 2 片。
- 守卫 `_env_guard.bat` 逐片校验存在性与总体积：缺片、只传第 2 片、只下到一半，全部在启动前拦截（退出码 `2`）。
- 启动器把别名中的分片后缀去掉，`/v1/models` 显示 `qwen2.5-7b-instruct-q6_k`，不会带 `00001-of-00002`。
- **禁止**改名、合并、只保留一片；分片元数据与文件名绑定在 `models\` 下保持只读。

环境变量（启动器生效）：`VANITAS_PORT` 覆盖端口、`VANITAS_PROFILE` 覆盖档位。未设置即生产默认行为。

统一 llama-server 参数（三个启动器一致）：

```bat
llama-server.exe -m "<模型>" --host 127.0.0.1 --port <端口> ^
    -c <ctx> -ngl 999 -np 1 -fa on ^
    -ctk <KV> -ctv <KV> ^
    -a "<模型别名>" -fit off --metrics
```

> 别名取文件名主干；若命中 `-00001-of-00002` 形式则截去 15 字符分片后缀。启动器不再自行统计体积，分片模型的“总 MB”由守卫统一给出，避免只算首片。

## 5. 显存预算（实测 vs `llama-fit-params` 预测）

| 场景 | 应用侧实测 | `llama-fit-params` 预测 | 整卡实测 | 结论 |
| :--- | ---: | ---: | ---: | :--- |
| 3B Q4_K_M @ 8K + Q4_0 | 约 2.1 GiB | — | 3,375 MiB | 实测 |
| Qwen 7B @ 4K + Q8_0 | 约 5.7–5.8 GiB | 5,980 MiB | 7,134–7,490 MiB | 实测，余量约 700–1,050 MiB |
| Qwen 7B @ 8K + Q4_0 | 约 5.8 GiB | 5,991 MiB | 7,153–7,417 MiB | 实测，与档位 1 基本同耗 |
| MiniCPM 2B @ 8K + F16 | 约 2.7 GiB | 2,894 MiB | 4,299–4,312 MiB | 实测，余量充足 |
| MiniCPM 2B @ 32K + F16 | 约 3.7 GiB | 3,926 MiB | 5,346 MiB | 实测，余量充足 |
| HY 7B @ 4K + Q8_0 | 约 6.0 GiB | 6,429 MiB | **7,613–7,634 MiB** | 实测通过，**余量仅约 550 MiB** |
| HY 7B @ 8K + Q4_0 | 未测 | 6,449 MiB | — | 预测比档位 1 更紧，暂不默认 |
| HY 7B @ 4K + F16 | 未测 | 6,669 MiB | — | 当前底噪下预计越界，不默认 |

> 结论：**HY-MT2 是本机最紧的模型**。桌面底噪若再涨约 600 MiB，HY 会先触发上限；Qwen 还有约 700 MiB 缓冲。预测与实测差 200–400 MiB，来源是 CUDA 图/日志缓冲与采样时刻差异。

## 6. 已知问题与规避

| 问题 | 影响 | 规避 |
| :--- | :--- | :--- |
| 8080 被 `steamwebhelper.exe`（PID 34724）占用 | Qwen 默认端口无法监听 | 退出 Steam；或 `set VANITAS_PORT=<空闲端口>`（本轮用 18080） |
| MiniCPM 实际是 Q8_0，而非早期文档的 Q6_K | 旧路径 `minicpm5-2b-instruct-q6_k.gguf` 不存在 | 已改名 `run_minicpm5_2b_q8.bat` + 默认路径改 `MiniCPM5-2B-Q8_0.gguf` |
| 7B 为 2 分片 | 传错分片或只下载一半会启动失败 | 守卫逐片校验；只传 `-00001-of-00002`；不改名/不合并 |
| MiniCPM5 默认思考，content 可能为空 | 短预算下 JSON 用例必判负 | 基准请求带 `enable_thinking=false`；生产侧同样建议显式关闭 |
| HY 显存余量只有约 550 MiB | 多开一个 GPU 应用就可能 OOM | 启动前用 `[5]` 看显存；先关壁纸引擎/浏览器 |
| llama-server 无 API Key 且 CORS 全开 | 同机任意进程可调用 | 只绑 `127.0.0.1`，不做端口映射 |
| SSE 分片 ≠ token | 用分片数算 t/s 会失真 | 性能只读服务端 `timings`/`usage`，分片仅校验流式协议 |
