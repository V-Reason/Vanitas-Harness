## 已知问题

| 问题 | 影响 | 规避/现状 |
| :--- | :--- | :--- |
| HY-MT2 显存余量仅约 500 MiB | 多开 GPU 应用可能 OOM | 启动前 `vanitas status`；先关壁纸引擎/浏览器 |
| V4 基线里无源句首「嗯…」19 条（V5 探测集 3/8） | 风格层噪声，非硬错 | 未做确定性后处理；V5 已压到个位，但只测 266 cue |
| V4 基线的「您」不看语域（V5 探测集 0） | 服务/亲密语境都可能偏 | QC 只在亲密语境点名；不宣称已解决 |
| S2/V1 仍有单字碎片、拟声误读、乱码残片 | 少数硬错 | 已加替换符拦截与 T1；`シーコ`/`しこしこ` 等需语义判断，未修 |
| `くに` 被误建为实体名 | `くにくに` 可能被示例自我强化 | 已记录；`capture_translations` 尚无质量判据 |
| 续传只校验 `(序号, 时间轴)` | 源文改字但时间轴不变会套旧译文 | 删 `.part.srt` 或去掉 `--resume` 重跑 |
| V5 仍会把纯假名音效位写成音译式人名（`コーリ`→「科里」、`カーリー`→「卡莉」） | 字幕里出现“像人名的拟声” | 提示词层已试过两版未收敛；`strip_example_names`/`invented_name` 只认提示词示例专名，抓不到这类 |
| `--jobs > 1` 实际串行 | 大批量不加速 | 服务端 `-np 1`；不是并发实现 |
| SSE 分片 ≠ token | 用分片数算 t/s 会失真 | 性能只读 `timings`/`usage` |
| HY 分词器告警 | 日志噪音 | 实测对话/翻译正常；未深究 |
| MiniCPM5 默认思考 | 短预算下 content 可能为空 | `template_kwargs.enable_thinking=false` 已配置 |
| 环境名有三处来源、batch 未路由 | 概念不一致风险 | `settings.translate.environment`、`--env`、`EnvironmentProfile.name`；batch 暂无 `--env` |
| `invented_name` 真机未观察到“嵌在正常句子里”的形态 | 规则只有单测覆盖 | 保留为防御项，不宣称真机收益 |

## 未验证边界（诚实标注）

1. **长上下文质量未测**：8K/32K 只验证可启动与短问答，未做长文档翻译/检索质量评估。
2. **并发未测**：`-np 1` 单槽；排队与并发显存行为未知。
3. **TTY 交互未真人验收**：历史/行编辑/Tab/Ctrl-C、`/status` 重绘、`/y/N` 观感只在伪 TTY 与单测下验证。
4. **`serve --foreground` 未实测**：会阻塞终端，未在自动化中执行。
5. **`.txt` 真机翻译未测**；`.md` 已做 2 文件目录小样本冒烟，`.mp4/.jpg` 只做仅改名冒烟。
6. **5xx 重试与真实故障注入未测**：重试矩阵只有代码与单测。
7. **断点续传未在真机语音上“打断再 resume”**：仅用真实 `translate_file` + 崩溃脚本覆盖。
8. **1000+ 句 ASMR 长音频未压测**：微批次合流在真实 GPU 上的显存、耗时与长期稳定性未知。
9. **V4 提示词未做 blind 语义 A/B**：P4 的 514-cue 盲测结论是 `INVALID_MEASUREMENT_UNREACHABLE`，不是 PASS/FAIL，也没有胜率；语料缺口仍在（`梵天/添寝/オマケ/綿棒` 在 1,404 cue 中命中 0）。
10. **防线 2/3/4 的收益未做全量 A/B**：标点归一、音近词族、元数据先验只有构造样例与局部回放。
11. **`minicpm` / `qwen7b` 未跑 80-cue 语义靶场**：`--model/--port` 已支持，但无实测数据。
12. **Agent 真实删除、shell 被拒后自动改用 `move_file`、`max_steps` 耗尽提示未验收**：qwen7b 的双文件创建、批量 `move_file`、`run_shell_ro` 拒绝与越界拦截已冒烟。
13. **路径约束是参数级沙盒，不是 OS 级隔离**：程序内部自行写文件仍需人工判断。
14. **`tools.max_capture_bytes` 只限制解码/反馈体积**：`subprocess.run` 捕获阶段峰值内存未压测。
15. **跨模型 `/model` 切换、真实终端颜色/进度闪烁未真人确认**：代码路径与 mock 单测已覆盖。

## 下一步

1. **注释门**（与编译门同级）：`scripts/check_comments.py` 拦四类腐化——取证外泄（run stamp / cue 号 /“实测 N 条”）、幽灵符号（注释里反引号的标识符已不存在）、悬空文档锚（`§n` 解析不到）、复读钉死值（把测试已钉死的字节/指纹写进注释）。
2. **音译式人名**：为“源文全假名非专名 + 译文恰为 2–3 汉字 + 延展号”设计确定性降级，扩 `strip_example_names` 的覆盖面；先写单测再上生产。
3. **V5 全量复验**：在 20 份 S2 语料上跑 V5，确认 266 cue 探测集的收益能外推；单轮不算结论。
3. **补确定性后处理**：源文无 `あ/ん/はぁ…` 时剥离句首叹词，优先解决 19 条无源「嗯…」；先写单测再上生产。
4. **实体质量**：给 `capture_translations` 加质量判据，阻止 `くに` 这类拟声碎片进入前文示例；不改现有锁定规则。
5. **长音频基准**：用 1000+ 句 ASMR 在真实 GPU 上跑微批次合流/局部回退，记录显存、墙钟、TTY 观感。
6. **真机补验**：`.txt` 翻译、真实终端 `[y/N]`/删除、`--resume` 打断恢复、`serve --foreground`。
7. **若桌面底噪长期 >1.7 GiB**：先降 Qwen 到 8K+Q4_0，HY 只保留 4K+Q8_0；不要在 `-fit off` 下打开系统内存回退。
