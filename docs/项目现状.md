## 5. 已知问题

| 问题 | 影响 | 规避 |
| :--- | :--- | :--- |
| HY 显存余量仅约 500 MiB | 多开一个 GPU 应用就可能 OOM | 启动前 `vanitas status` 看显存；先关壁纸引擎/浏览器 |
| 单实例策略会回收旧服务端 | 同时只能服务一个模型 | 需要切换时先 `stop`，或直接 `serve` 新模型（守卫会回收） |
| MiniCPM5 默认思考 | 短预算下 content 为空 | 配置已带 `enable_thinking=false`；自定义模型须显式关闭 |
| 7B 为 2 分片 | 传错分片或只下载一半会启动失败 | 守卫逐片校验；只传 `-00001-of-00002` |
| 端口 8080 段被 Steam 占用 | 旧文档的默认端口不可用 | 已迁到 4060–4063；必要时 `VANITAS_PORT` |
| 管道输入按 UTF-8 解码 | 从 cmd 以 cp936 管道喂中文会乱码/替换 | 用 PowerShell 7 或先写 UTF-8 文件再重定向 |
| 混合换行的 `.srt`（同文件内 `\n` 与 `\r\n` 并存） | `_detect_eol` 取首个出现的 EOL 切行，块识别失败 → 整篇按原文写回并报 `✓ … · 0 段`，退出码仍是 `0`（**静默不翻译**） | 翻译前用编辑器统一换行；修复方案（`parse_srt` 改 `re.split(r"\r\n\|\n\|\r")`）已定位，尚未实施 |
| SSE 分片 ≠ token | 用分片数算 t/s 会失真 | 性能只读 `timings`/`usage` |
| `--jobs > 1` 实际串行 | 大批量不会加速 | 已知限制；服务端 `-np 1` |
| HY 分词器告警（`special_eos_id` / `n_ctx_train=0`） | 日志噪音 | 实测对话与翻译正常，未深究 |
| prompt_toolkit 的 TTY 编辑路径未验证 | 交互体验未经真人终端确认 | 缺失时自动降级 `input()`，功能不受阻 |

## 6. 未验证边界（诚实标注）

1. **长上下文质量未测**：8K/32K 只验证可启动与短问答，未做长文档翻译/检索质量评估。
2. **并发未测**：`-np 1` 单槽，所有吞吐均为单流；排队与并发显存行为未知。
3. **TTY 交互未实测**：`prompt_toolkit` 历史/行编辑仅在非 TTY 管道下验证了降级路径。
4. **跨模型 `/model` 切换未实测**：单实例下需要第二个已就绪服务端，本轮未构造。
5. **`serve --foreground` 未实测**：会阻塞终端，未在自动化中执行。
6. **`.txt` / `.md` 真机翻译未测**：仅单测覆盖分段与空行；真机只跑了 `.srt`。
7. **重试路径未实测**：4xx 不重试与 5xx 退避逻辑只有代码与单测，没有真实故障注入。
8. **多轮对话未跑满预算**：`session.trim` 用脚本验证（80 条/6,720 tokens → 42 条/3,528，丢 19 轮），未做长对话体验评估。
9. **HY 的 8K+Q4_0、4K+F16 与 Qwen 4K+F16 未测**：仅有 `llama-fit-params` 预测。
10. **驱动「首选不回退」未核验**：无溢出样本；持续负载/温度墙也未压测。
11. **v0.4.1 的界面观感未真人验收**：16 色主题与三处 `⋯` 覆盖式进度只在「强制 `always` 抓字节」与「伪 TTY 单测」下验证，真实交互终端的闪烁、行宽残留、`prompt_toolkit` 重绘叠加均未确认。

## 8. v0.4.1 变更摘要

- **输出契约**：CLI 全量去除 `[GUARD-CODE=N]` 与所有方括号标签；退出码语义不变（`0/1/2/3/4/5`，守卫 `0/1/2/3/4/9`），消息改为 `✓/✗/⚠/⋯/·/提示：` 前缀，退出码是唯一机读契约。
- **着色**：新增 `vanitas/ui.py`（17 色名 → ANSI、符号表、`enable_vt()` 走 `ctypes` 开 Windows VT）与 `config/settings.json` 的 `ui` 段（`color: auto|always|never` + 7 键主题）；`ui` 段缺失自动回落默认，旧配置零迁移。`auto` 要求 stdout 与 stderr 都是终端，重定向即纯文本。
- **提示符**：`vanitas[qwen7b:1]> ` → `qwen7b@1 › `；`/status` 改为 `· 模型/档位/端口/GPU/会话` 多行样式，PID 与日志路径收进 `-v`。
- **进度反馈**：新增 `vanitas/progress.py`（TTY 覆盖式单行、非 TTY 静默）接入三处——加载期 `⋯ 正在加载模型 Ns`、生成首字前 `⋯ 正在生成 Ns`、翻译逐段 `⋯ 正在翻译 a.srt（2/3）`；完成行由 `Spinner.done()` 统一输出。
- **兼容面**：`launcher.wait_ready(config, record, palette=None, *, progress=True)`、`translate.translate_file(..., on_segment=None)` 均为可选参数扩展，不传时行为与 v0.4.0 一致。
- **单测**：61 → **90**（新增 `test_ui.py` 11、`test_progress.py` 7；config +6、guard +3、translate +2、cli_smoke +1；删除已失效的 `[GUARD-CODE]` 用例）。
- **未做**：混合换行 SRT 的解析修复（见第 5 节）、真实 TTY 观感验收（见第 6 节第 11 条）、`serve --foreground` 的进度反馈。
